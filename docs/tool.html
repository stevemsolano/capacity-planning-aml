Capacity Planning Tool — AML/KYC

How many analysts do we need next quarter, what happens to backlog and SLA if demand moves, and what does it cost to cover it with overtime vs hiring? Every number below is computed live by the same engine as the Python pipeline (src/forecast/monthly_forecast.py) — same base demand, same ramp, same attrition, same costs. Change any input and the forecast, the charts and the sensitivity analysis all recompute.

How it is orchestrated

Generate · seed 42→Load · DuckDB→dbt · staging → marts→Prefect flow→Forecast · Backtest · Monte Carlo→GitHub Actions CI · 24 tests→Tableau Public

Run it yourself: python3 flows/capacity_pipeline.py — the JS engine on this page mirrors that pipeline exactly. Prefect is optional: with it installed the steps run as a flow with retries, logs and schedule; without it they run as plain functions with identical logic. Airflow is mapped 1:1 in docs/orchestration.md.

Scenario — what changes?

Measured trend on 90 days is −4.01%/mo. It is not auto-applied: compounding a noisy OLS slope would cut the M3 backlog from 7,936 to ~2,900 on noise alone. You set it — the model does not invent it.

Levers — what do we do about it?

Hires ramp 50% in weeks 1–2, 75% in weeks 3–4, 100% after. Overtime is total team hours per day, not per analyst. Costs (illustrative): $30/h base, $45/h overtime, $72,000/yr per hire + $5,000 onboarding.
